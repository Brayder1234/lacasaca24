# La Casaca 24 — Catálogo

Catálogo web de camisetas de fútbol de **La Casaca 24** (@lacasaca_24_). La pasión que viste.

- 139 camisetas retro de clubes y selecciones, con buscador por equipo, año o jugador.
- Ficha por camiseta: corte, talla, personalización (nombre, número y parches) y precio.
- Pedido directo por WhatsApp, guía de tallas con calculadora y sección de reseñas.

Todo vive en `index.html` (imágenes incluidas). Para editar precios o el número de WhatsApp, busca el bloque `CONFIGURACIÓN` al inicio del script.
